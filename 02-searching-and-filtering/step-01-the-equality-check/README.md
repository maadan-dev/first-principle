# Step 01: The Equality Check 🎯

## The Idea
Before searching a whole list, let's look at the atomic check:
How do you ask Python: *"Is this item equal to what I am looking for?"*

In Python, we compare two values using `==`:

```python
if item == target:
    # Found it!
```
