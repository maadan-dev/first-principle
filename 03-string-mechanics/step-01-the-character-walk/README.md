# Step 01: The Character Walk 🔤

## The Idea
In Python, strings are just sequences of characters. You can loop through a string just like a list:

```python
text = "hello"
for char in text:
    print(char)
```

Prints `'h'`, then `'e'`, then `'l'`, etc.
